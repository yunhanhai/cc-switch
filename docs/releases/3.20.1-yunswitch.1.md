# YunSwitch 3.20.1-yunswitch.1 预发布准备

本次从 CC Switch v3.20.1 的二次开发线分配独立版本，作者与 MIT 来源信息继续保留。公开 Release 与标签尚未创建，以下记录用于审阅源码及本机产物。

## 本版变化

- 应用展示名 YunSwitch、独立应用 ID、Windows 安装 UpgradeCode 与自启动名称。
- 发布目录 `.yunswitch`、开发目录 `.yunswitch-dev`，分别注册 `yunswitch://`、`yunswitch-dev://`。
- 新数据库使用独立端口，现有配置保留；Claude Desktop 使用独立 profile。
- 四语界面品牌、首页文档、问题反馈和发布入口对应本人仓库。继承供应商优惠文案改为中性说明。
- 上游更新公钥移除，自动更新与 R2 镜像默认停用。发布流程允许未配置签名时构建预发布包；不宣称 Windows 已签名或 macOS 已公证。
- [迁移指南](../MIGRATION-YUNSWITCH.md)解释旧数据导入、CLI 接管与免安装包目录行为。

供应商预设中部分推荐参数与排序元数据仍继承自上游，目前隐藏合作徽标且不宣称本项目享有相关合作关系；后续将单独审阅这些预设。

## 验证记录

本次代码与安装包检查结果将在验证完成后补充。此前 `main` 的跨平台 CI 已通过，不能代替本次身份调整的检查。

首次安装、交互启动、卸载、从旧版迁移和签名更新需在隔离环境中另行验证。当前电脑的真实 CLI 和密钥配置没有作为安装测试环境。
