# YunSwitch 3.20.1-yunswitch.6 Windows x64 预发布准备

本版继续改进原生 Codex Responses 的输出前错误恢复。源码版本 `3.20.1-yunswitch.6`，MSI 版本 `3.20.1.6`；当前公开包仍是[`.5`](3.20.1-yunswitch.5.md)，本页在新包完成验证后补充下载、源码和产物记录。

## 本版变化

- 原生 API Key Codex Responses 对 gzip / x-gzip、zlib 或常见 raw deflate、Brotli、zstd / zst 响应增量解码，明确的输出前限流进入现有等待和重试策略。
- 限制压缩输入、解码输出和每层中间数据的字节预算；最多处理四层编码，zstd 窗口最多 8 MiB。未知编码或过深编码栈保留原体与头；已知编码损坏或截断会报错。
- 等待状态由每个请求独立持有。并发成功不会清掉其他请求的等待提示，等待结束或取消只清理所属条目；等待文本不再写入最后错误。
- 半开熔断探测由请求持有，取消时中性释放，不增加供应商失败统计。旧请求在手动重置后取消，也不会释放后来请求的探测名额。
- 增加绿色版及 `.5` 升级后程序中的压缩限流、输出后禁止重试、最终 429 / Retry-After 和并发取消检查。增量解码依赖的 MIT 许可随安装包分发。

## 验证与产物

准备中。需要完成最终源码 CI、Windows 新包构建与实际运行验收、`.5` MSI 升级、产物 SHA-256 和许可回读后再公开。

## 使用边界

重试设置保持用户原有选择。恢复仅覆盖可重建的原生 API Key Codex Responses 请求；官方账号、跨协议转换、状态引用和服务器执行工具沿用原有处理。任何已有文本、推理或工具活动后的失败都不会自动重放。本版不保证所有 API 网站或编程代理的长任务都能自动续跑。

默认发布 Windows x64，签名与自动更新仍关闭。测试使用合成历史、虚构密钥及回环上游，实际供应商和真实长会话需分别验证。设置与边界见[输出前恢复说明](../CODEX-STREAM-RECOVERY.md)。
