# YunSwitch 3.20.1-yunswitch.6 Windows x64 预发布

2026-11-13，Windows x64 在 [GitHub](https://github.com/yunhanhai/yunswitch/releases/tag/v3.20.1-yunswitch.6) 和 [Gitee](https://gitee.com/yunhanhai/yunswitch/releases/tag/v3.20.1-yunswitch.6) 同步公开。源码版本 `3.20.1-yunswitch.6`，MSI `3.20.1.6`，沿用独立身份、数据目录和 UpgradeCode。上版 [`.5`](3.20.1-yunswitch.5.md) 的附件保留。

## 本版变化

- 受支持的压缩 Codex Responses 逐块解码，明确输出前限流使用现有等待与重试；gzip / x-gzip、zlib / 常见 raw deflate、Brotli、zstd / zst 均有回归覆盖。
- 压缩输入与每层输出最多 128 MiB，最多四层编码，zstd 窗口最多 8 MiB。未知编码或过深编码栈保留原体与头，已知编码损坏/截断报错。
- 等待由各请求独立持有，其他请求成功不会清掉存活的等待提示，取消只清理所属条目。半开探测自动中性释放，手动重置后旧请求也不能释放新探测。
- 便携与升级后程序增加压缩限流、已有输出后禁止重试、最终 429 / Retry-After、并发成功和取消后停止重试验收。增量解码依赖的 MIT 原文随包分发。
