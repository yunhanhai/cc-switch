# YunSwitch 3.20.1-yunswitch.2 Windows x64 预发布准备

2026-11-10，当前源码版本已分配为 `3.20.1-yunswitch.2`，Windows MSI 安装版本为 `3.20.1.2`。新包仍在准备，尚未创建公开发布；已公开的上一版及校验信息见[首版记录](3.20.1-yunswitch.1.md)。上游基线继续为 CC Switch v3.20.1，原作者署名与 MIT 条款保留。

## 本版变化

- 清理内置供应商网站和 API Key 获取链接中继承的推广归因与邀请路径，保留控制台路径、购买查询和 SPA 路由。
- 移除内置商业标记与无功能提示键。默认列表为官方预设优先，其余按显示名称排序。
- 保留 Gemini 认证依赖的 `google-official` 与 `packycode` 兼容键；预设数量、顺序、请求地址、模型与认证配置未改变，已有用户配置不执行清洗或迁移。
- 四语言 README 和项目文档补充实际验证范围，继续区分 Windows 安装验收、macOS/Linux 源码 CI 与 ARM64 尚未验收状态。

目录维护已通过[源码 CI](https://github.com/yunhanhai/yunswitch/actions/runs/42830596094)：143 个前端测试文件、1095 项测试全部通过。该记录对应目录维护提交，不代替本版最终源码检查或安装包验收。

## 新包验收与发布计划

本版仅准备 Windows x64 MSI 与便携 ZIP。新包将使用干净 GitHub-hosted Windows runner 验证首次欢迎、实际界面、模拟代理请求、重启、单实例、合成旧 SQL 导入、卸载及数据保留，并增加从上一版 MSI 的安装升级检查。

Windows UpgradeCode 沿用独立身份，MSI 版本递增；升级检查需要确认旧安装替换、协议和快捷方式登记以及合成数据库保留。源码、安装包 SHA-256、运行记录与截图将在验收完成后补充，此时不声明已通过。

验收通过后，Gitee 与 GitHub 将发布同一批已核验文件，分别提供 MSI、便携 ZIP 与同名 `.sha256`。Windows Authenticode 签名尚未配置，应用内自动更新继续关闭。其他平台仍需独立构建与安装验收。

旧 CC Switch 数据迁移仍按[迁移指南](../MIGRATION-YUNSWITCH.md)使用私有备份导入。本次自动验收只使用合成数据，不测试真实付费供应商与用户私人数据。
