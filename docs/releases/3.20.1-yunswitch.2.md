# YunSwitch 3.20.1-yunswitch.2 Windows x64 预发布

2026-11-10，Windows x64 安装版与便携 ZIP 已在 [GitHub](https://github.com/yunhanhai/yunswitch/releases/tag/v3.20.1-yunswitch.2) 和 [Gitee](https://gitee.com/yunhanhai/yunswitch/releases/tag/v3.20.1-yunswitch.2) 同步公开。源码版本为 `3.20.1-yunswitch.2`，MSI 安装版本为 `3.20.1.2`。上游基线继续为 CC Switch v3.20.1，原作者署名与 MIT 条款保留；首版历史见[`.1` 发布记录](3.20.1-yunswitch.1.md)。

## 本版变化

- 清理内置供应商网站和 API Key 获取链接中继承的推广归因与邀请路径，保留控制台路径、购买查询和 SPA 路由。
- 移除内置商业标记与无功能提示键。默认列表为官方预设优先，其余按显示名称排序。
- 保留 Gemini 认证依赖的 `google-official` 与 `packycode` 兼容键；预设数量、顺序、请求地址、模型与认证配置未改变，已有用户配置不执行清洗或迁移。
- 四语言 README 和项目文档补充实际验证范围，继续区分 Windows 安装验收、macOS/Linux 源码 CI 与 ARM64 尚未验收状态。
- 安装验收增加从首版 MSI 升级的检查，核对产品替换、数据保留及升级后协议、快捷方式、许可证和单实例。

## 已完成验证

[最终源码 CI](https://github.com/yunhanhai/yunswitch/actions/runs/42835576117)全部通过：143 个前端测试文件、1095 项测试，三平台 Rust 格式检查、严格 Clippy 与后端测试，以及 Windows→WSL2 的文件替换检查。

| 源码验证环境 | 单元测试通过 | 集成测试通过 | 忽略 |
| ------------ | -----------: | -----------: | ---: |
| Windows      |         2858 |          128 |    6 |
| macOS        |         2880 |          128 |    5 |
| Linux        |         2863 |          127 |    5 |

不同平台的条件编译测试范围不同。macOS/Linux 通过源码检查，尚未提供独立安装包及安装验收。

Windows 两轮验收均通过 35 项运行检查：首次欢迎、实际界面加载与截图、模拟代理请求、退出和重启、单实例、合成旧 SQL schema v1→v20 导入、MSI 安装、独立协议/快捷方式/许可证、卸载及数据库保留、卸载后便携读取。

首版 `.1`→`.2` MSI 升级已实际通过：旧产品登记移除、新产品安装，安装期间数据库 SHA-256 未变，上一版创建的供应商和设置保留，升级后的程序、协议、快捷方式、许可证与单实例正确。升级截图显示迁移供应商及上一版新增供应商均可读取。MSI 忽略版本号第四段作升级比较；现有 `AllowSameVersionUpgrades=yes` 配置支持此次替换，以上结论来自实际安装验收。

## 升级与验证边界

从 YunSwitch `.1` 升级时退出应用，再运行新版 MSI。旧 CC Switch 数据仍按[迁移指南](../MIGRATION-YUNSWITCH.md)使用私有备份导入；同一 CLI 配置由一个应用管理。

本版只提供已验收的 Windows x64 包。Windows Authenticode 签名尚未配置，应用内自动更新继续关闭；macOS、Linux 和 ARM64 包尚未发布，ARM64 尚未完成独立验收。自动测试使用合成数据与模拟上游，不代表所有真实付费供应商连通性或用户私有数据迁移均已验证。
