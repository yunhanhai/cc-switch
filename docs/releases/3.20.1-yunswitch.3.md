# YunSwitch 3.20.1-yunswitch.3 Windows x64 预发布

2026-11-11，Windows x64 安装版与便携 ZIP 已在 [GitHub](https://github.com/yunhanhai/yunswitch/releases/tag/v3.20.1-yunswitch.3) 和 [Gitee](https://gitee.com/yunhanhai/yunswitch/releases/tag/v3.20.1-yunswitch.3) 同步公开。源码版本为 `3.20.1-yunswitch.3`，MSI 安装版本为 `3.20.1.3`。继续基于 CC Switch v3.20.1 独立维护，保留原作者署名与 MIT 条款；上一版见[`.2` 发布记录](3.20.1-yunswitch.2.md)。

## 本版变化

- 随附已核实的 CodexBar 与 LobeHub MIT 原文许可副本、第三方通知和图标来源记录。
- Windows MSI 包含原文 `LICENSE`、`LICENSE.rtf`、`THIRD-PARTY-NOTICES.md` 与 `licenses/` 中两份许可；便携 ZIP 包含对应原文通知与许可。
- Windows 正式版与开发版使用各自固定的 WiX 组件 GUID 和 HKCU key path。
- 便携包、首次安装和升级后逐字节验证通知与许可，两次卸载检查文件目录及注册项清除。

来源见[开源来源台账](../PROVENANCE.md)、[图标来源](../ICON-SOURCES.md)和[许可分发](../THIRD-PARTY-PACKAGING.md)。49 个独立 SVG 已匹配历史固定 LobeHub 包；其余图标、位图、自定义资源及依赖许可仍逐项核查，本版不构成全量许可审计。

## 升级与验证边界

从 YunSwitch `.2` 升级前退出应用，再运行新版 MSI；旧 CC Switch 数据按[迁移指南](../MIGRATION-YUNSWITCH.md)使用私有备份导入。

本版仅发布 Windows x64。Windows Authenticode 签名尚未配置，应用内自动更新关闭；macOS/Linux 仅完成源码测试与通知资源配置，未发布独立包或完成安装验收，ARM64 尚未验收。自动测试使用合成数据与模拟上游，不使用用户私人配置、真实密钥或对话，不代表全部真实供应商已验证。

已公开 `.1`、`.2` 标签和附件保留其历史内容，本次使用新版本分发许可文件。
