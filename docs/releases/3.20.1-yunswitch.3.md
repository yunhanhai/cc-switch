# YunSwitch 3.20.1-yunswitch.3 Windows x64 预发布准备

2026-11-11，当前源码版本分配为 `3.20.1-yunswitch.3`，Windows MSI 安装版本为 `3.20.1.3`。新包尚未发布，当前公开下载仍为[`.2` 版本](3.20.1-yunswitch.2.md)。本版继续基于 CC Switch v3.20.1 独立维护，原作者署名与 MIT 条款保留。

## 本版变化

- 保留已核实的 CodexBar 与 LobeHub MIT 原文许可副本，新增第三方通知和图标来源记录。
- Windows MSI 随附原文 `LICENSE`、已有 `LICENSE.rtf`、`THIRD-PARTY-NOTICES.md` 与 `licenses/` 中两份许可；便携 ZIP 包含对应通知与原文文件。
- Windows 正式版与开发版使用各自固定的 WiX 组件 GUID 和 HKCU key path，避免两种安装身份混用文件组件。
- 验收逐字节检查安装目录及便携包中的通知与许可，复验同时核对构建所用的许可源文件。

来源记录见[开源来源台账](../PROVENANCE.md)、[图标来源](../ICON-SOURCES.md)和[许可分发配置](../THIRD-PARTY-PACKAGING.md)。49 个独立 SVG 已匹配历史固定 LobeHub 包；其余图标、位图、自定义资源和依赖许可仍需逐项核查，不将本版描述为全量许可审计。

## 新包验证计划

此前本机 MSI 重新打包与文件提取、便携 ZIP 模拟打包已核对许可文本，但不代替本版的新构建或实际安装验收。

本版仅准备 Windows x64 安装版与便携 ZIP。使用干净 GitHub-hosted runner 验证首次欢迎、实际界面、模拟代理请求、重启、单实例、合成旧 SQL 导入，以及从已公开 `.2` MSI 升级后的产品替换、供应商与设置保留、协议与快捷方式。

首次安装及升级后将核对完整通知与许可内容；卸载需确认程序、通知组件和登记移除、数据库保留，并验证便携包可继续读取数据。源码 CI、构建提交、验收运行、截图与最终文件 SHA-256 在实际完成后补充。

新标签和两边公开发行将在验收及文件核对通过后建立。`.1`、`.2` 标签与已有附件保持历史状态，不用重新打包文件替换旧版。

Windows Authenticode 签名尚未配置，自动更新继续关闭。macOS/Linux 的通知资源映射已配置，但独立包与安装验收尚未完成；ARM64 尚未验收。真实供应商和私人数据不用于自动测试，旧 CC Switch 数据迁移仍按[迁移指南](../MIGRATION-YUNSWITCH.md)处理。
