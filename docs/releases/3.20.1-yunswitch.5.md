# YunSwitch 3.20.1-yunswitch.5 Windows x64 预发布

准备中，尚未公开新安装包。源码版本 `3.20.1-yunswitch.5`，MSI 版本 `3.20.1.5`，沿用独立应用身份、数据目录和 UpgradeCode。当前已公开版本见[`.4` 发布记录](3.20.1-yunswitch.4.md)。

## 本版变化

- 原生 Codex Responses 在输出交付前识别 HTTP 200 响应中的明确限流和服务端暂时失败，复用现有等待、同家重试与故障转移设置。
- 失败流前缀不混入最终成功输出；已有输出、工具事件、未知扩展和不可重建状态保持原样，避免重复工具调用。
- 检查具有时间、字节和数据块上限，心跳不延长窗口。明确参数/密文错误保留错误码和可操作指引。
- 增加实际 Windows 程序的流内 429 / 服务端错误恢复、输出后禁止重试和 `.4` 升级验收。

设置与限制见[输出前恢复说明](../CODEX-STREAM-RECOVERY.md)。加密历史兼容与重试设置独立，已有偏好不自动变更。

## 验证状态

完成本轮源码测试、跨平台 CI、Windows 全新构建及干净 runner 安装升级验收后，在此记录最终源码、产物、校验值和公开入口。测试只使用合成历史、虚构密钥和回环上游。

## 使用边界

仅计划发布 Windows x64，签名及自动更新仍关闭。官方账号、跨协议转换、压缩流、服务器执行工具和状态引用不套用新恢复；已输出后的流中断无法通用恢复，也不保证编程代理自动继续任务。`.4` 及更早包保持各自历史内容。
