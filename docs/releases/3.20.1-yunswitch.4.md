# YunSwitch 3.20.1-yunswitch.4 Windows x64 预发布

准备中，尚未公开安装包。源码版本为 `3.20.1-yunswitch.4`，MSI 安装版本为 `3.20.1.4`，沿用独立应用身份和 UpgradeCode。已公开的上一版见[`.3` 发布记录](3.20.1-yunswitch.3.md)。

## 本版变化

- 新增默认关闭的 **Codex 加密历史兼容**，通过 YunSwitch 原生代理清理池化 Responses 网关无法解密的回放历史，不需要单独运行 Node shim。
- 处理原生 Responses 的 API Key 供应商，不按网站域名限制；保留明文、工具调用关系、`phase` 和用户 JSON，拒绝无法重建的压缩历史与状态引用。
- 修复最终 Codex 限流响应，保留 HTTP 429、`Retry-After` 和等待秒数；已有重试、退避和故障转移按各自设置继续工作。
- 修复停止代理后旧 HTTP 长连接仍继续处理请求的问题；停止时回收所有连接，重新启动后请求使用新实例，避免路由和等待统计留在旧实例。
- Windows 安装版与便携包附 AgentRouter Responses Shim 的 MIT 原文及来源记录。

开关入口为**设置 → 路由 → 整流器 → Codex 加密历史兼容**。应先启动本地代理并让 Codex 请求经过 YunSwitch；它不会修改本地会话历史，关闭后新请求恢复原有处理。详细适用范围和重试设置见[兼容说明](../CODEX-RESPONSES-COMPATIBILITY.md)。

## 验证计划与状态

功能提交 `725b7f8419da48c866a42ccfd9ca00587bfb63ae` 的[源码 CI](https://github.com/yunhanhai/yunswitch/actions/runs/42955978220)已通过：前端 144 个文件、1099 项测试，Windows/macOS/Linux 后端与 WSL2 文件系统检查。

本版本需重新构建并通过干净 Windows runner 验收，包括：便携/安装启动、实际界面、开关默认关闭及保存、重启保留、模拟池化网关 JSON/SSE 转发、压缩历史在出站前拒绝、429 等待后成功及最终 429 返回、许可内容、`.3`→`.4` 升级、旧设置保留、单实例、迁移和卸载。完成后在此记录源码、构建、验收、标签及产物 SHA-256。

首轮包验收先修正 Radix 标签页的脚本操作；随后发现旧 keep-alive 连接跨代理停止/重启存活，实际请求与界面统计属于不同实例。两个回归测试在修复前均失败，连接生命周期已修复；旧构建不再作为本版候选，须从修复源码全新构建并复验。

## 使用边界

删除推理密文可能减少上下文。官方账号/OAuth、Chat Completions/Anthropic 转换路径、`/responses/compact` 和绕过本地代理的请求不执行此修复；已输出后的流中断和所有 HTTP 200 流内错误没有通用自动恢复。429 等待默认关闭，同一家重试默认 0 次，升级不会自行更改这些偏好。

仅计划分发 Windows x64，签名与自动更新状态沿用 `.3`。测试只使用合成历史、虚构密钥和回环上游，不能替代所有真实供应商及长会话验证。现有公开版本附件保持其历史内容。
