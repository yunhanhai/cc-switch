# YunSwitch 3.20.1-yunswitch.7 Windows x64 预发布

2026-11-14，Windows x64 在 [GitHub](https://github.com/yunhanhai/yunswitch/releases/tag/v3.20.1-yunswitch.7) 和 [Gitee](https://gitee.com/yunhanhai/yunswitch/releases/tag/v3.20.1-yunswitch.7) 同步公开。源码 `3.20.1-yunswitch.7`，MSI `3.20.1.7`，沿用独立身份、数据目录及 UpgradeCode。上一版 [`.6`](3.20.1-yunswitch.6.md) 的附件保留。

## 本版变化

- 原生 API Key Codex Responses 的后台任务、会话/响应引用、压缩历史和服务器执行工具请求遇 HTTP 错误或断连后只发一次，不进入同家、整流或备用供应商重发。
- 成功只清理发送前已知的冷却，旧请求不能清掉并发的新限流窗口；剩余不足一秒向上取整。
- 明确结构化额度耗尽不进入 429 等待循环；消息里提到 quota 不作为该判断依据。重复 Retry-After 使用最长有效值，无有效头才读取结构化错误等待值；数字溢出不再退回短重试。
- 保留原有重试偏好和输出后不重放规则；便携与升级后程序新增五组运行检查。
